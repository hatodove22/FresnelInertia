# 「中身」を、指先に。— 動作原理

日本語音声はAI合成（Microsoft Edge TTS / ja-JP-NanamiNeural）。
模式アニメーションであり、実機の記録・計測映像ではありません。

## 01 / THE IDEA — 「中身」を、指先に。

空っぽの容器に、中身があるような感覚を。

二つの指先の傾きと、四つの振動を重ねて、動く中身の手がかりをつくります。

## 02 / ONE SHARED STATE — すべては、同じ中身から。

手の動きから、容器内の位置や速度を計算します。

寸法や充填率も応答を変えます。触覚の運動モデルは、本体のエックス・ワイ断面です。

## 03 / TWO COMPLEMENTARY OUTPUTS — ゆっくり、傾く。瞬間に、響く。

方向や慣性の手がかりは、二つの指先の接触面の傾きへ。

衝突や流れ、質感は四つの振動子へ。同じ中身から、二つの出力を生みます。

## 04 / THE HAPTIC PIPELINE — 動きを、触れる信号へ。

中身の運動から、壁に触れた瞬間を検出。

短い質感をつくり、振動子の再生信号に変換。最後に、四つの出力へ配置します。

## 05 / SPATIAL RENDERING — どこで、触れたか。

衝突した壁を中心に、振動を配ります。

流れは、隣り合う壁に時間をずらして送ります。強さだけでなく、順序も手がかりです。

## 06 / MATERIAL EXPRESSION — 同じ仕組みで、中身が変わる。

ビー玉なら、壁にコツン。砂なら、小さな接触が重なります。

液体は、揺れと流れを表現します。その自然さは、今後も調整する部分です。

## 07 / ON-DEVICE + HAPTIC LINK — 計算は、手の中で。

触覚の計算は、手の中のアトム・エス・スリーで行います。

ハプティック・リンクで、ウェブが設定を送り、デバイスが返す状態を表示します。

傾斜と振動、デスクトップ表示の連動は、実機で確認しています。
