## このHWに向く問い

「押すと何Nで返るか」よりも、「持って動かすと、中で何が起きるか」が
この構成の得意な出発点です。2枚の接触面はゆっくりした偏りや追従を、
4点の振動は接触の始まり・流れ・終わりを表現できます。
両者を同じ状態から作ることで、動きの履歴が体験に意味を与えます。

先行研究を踏まえて、次の軸を設計用にまとめました。新しい知覚分類や
実証済みのインタラクション空間を主張するものではありません。
引用の内容と適用範囲は[原典の監査](33_INTERACTION_RESEARCH_SOURCES.md)を参照。

| 設計の軸 | 選択肢 | 現機への含意 |
|---|---|---|
| 知りたいこと | 何が入っている／どこにいる／動くか／変わったか | 知りたい性質に合わせて探索動作を選ぶ（S01）。 |
| 手の動き | 保持／傾ける／揺する／静止／反転 | IMUで扱える。指の走査や押す力は別の入力が必要。 |
| 時間 | 持続する偏り／接触の始まり／移動／衝突／減衰／無音 | 接触面と振動に違う情報を持たせる（S03、S05、S12、S13）。 |
| 履歴 | 可逆な移動／吸着／残量／破砕／目覚め | 説得力のある遷移には、状態を共有し続ける必要がある。 |
| 中身の構成 | 単一物体／分布した粒／液体／壁に付着／出口 | 現在の容器接触から、どのモデル拡張が必要かを切り分ける。 |
| 座標 | 箱の中／外部の机・器・相手 | IMUだけで安定した世界座標の位置を得たことにはならない。 |
| 力の意味 | 荷重を表す手がかり／実際の抵抗・重心変化 | 実移動する錘、ブレーキ、連結機構は別の能力（S07、S08、S11）。 |

各指1軸の接触面は任意方向の面法線を提示する3自由度機構ではありません。
現行の中身の運動はbody x/yの断面モデルです。握力は設定値で、実測FSRは
ありません。S02の曲率結果、S09の輪によるせん断、S10の指腹から退避する
機構を、そのまま現機の能力として扱いません。

## 12の体験案

各案の完全なレシピは[図鑑のデータ](../../explainer/src/atlas/atlas-data.json)
にあります。手の動き・共有状態・遅い出力・速い出力・視覚・追加実装・
限界・比較実験・引用をひと組にし、画面とダウンロードで同じ内容を使います。

| ID / 体験 | 何が面白いか | 試すために必要なもの | 最初に確かめたいこと |
|---|---|---|---|
| C01 見えない標本箱 | 見る前に中身を当てる | 既存状態を隠す／明かすUI、停止中の条件切替 | 剛体と粒の違いが視覚なしでも分かるか。 |
| C02 伸びる秘密の空洞 | 跳ね返りの待ち時間から長さを知る | 適用済み寸法を用いた比較と開示 | 見えない長短の順序が分かるか（S04）。 |
| C03 火種を育てる | 壁にぶつけず中央で静かに支える | 既存位置とイベント数から粗い保持スコアを計算 | 傾きが修正を助けるか、振動だけと比べる。 |
| C04 最後の一粒 | 残量が減り、最後の接触から静寂へ | 出口・流出・残量の実機モデルと報告状態 | 残量に連動する傾きが、終了を分かりやすくするか。 |
| C05 くっつく積み荷 | 転がる、張り付く、離れる | 付着状態・離脱条件・イベント | 単に粘い玉と「止まってから外れる玉」を区別できるか。 |
| C06 手の中の小さな命 | 振ると目覚め、静かにすると眠る | 目覚め状態・自発運動・接触を生む実機の規則 | 同じ強さの無関係な振動より、内部から動くように感じるか。 |
| C07 結晶が砂に変わる | 壊れた後に、中身の振る舞いも変わる | 損傷蓄積・破砕後の内容状態・連続する運動 | 破砕音だけの場合より、前後の材質変化が伝わるか。 |
| C08 傾けて奏でる | 玉が境界を通ると音と指先が応える | 位置による発音領域、イベント時刻、ホスト同期 | 触覚と音のずれが邪魔にならないか。 |
| C09 ポケットの天気 | 手の中の嵐を、ゆっくり静める | 天候エネルギーと共有する擾乱・接触状態 | 物語に沿う変化が、単なる強弱から区別できるか。 |
| C10 小さな運び屋 | ARの器へ中身を注ぎ、残りを持ち帰る | 位置追跡・器との関係・移送量・追跡喪失時の方針 | 空間上の接触と移送が一致し、追跡喪失で誤移送しないか。 |
| C11 触って発掘する | 砂を払い、埋まったものをたどる | 面上の走査位置、表面状態、1軸への投影 | 小さな既知の走査範囲で、層の遷移が分かるか。 |
| C12 握って花を開く | 柔らかく握って、開花を促す | 握力・開口幅の計測と変形／抵抗の機構 | 規定した握りと変形の対応を実測で確かめる。 |

最も近いC01〜C03も完成済みのゲームではありません。現行の運動と出力を
変えずに、提示と課題を足す候補です。C04〜C09は現行HWを使える見込みですが、
新しいFWの状態・規則が必要です。C10〜C11は追跡、C12は計測・機構の追加が
前提です。色分けはこの条件の違いであり、実現確率や魅力度の点数ではありません。

## 拡張を実装する場所

今回の整理で、FWは[HapticSynthesisCore](30_REUSABLE_FIRMWARE_CORE.md)、
ビジュアルは[純粋な状態変換と描画部品](31_REUSABLE_VISUAL_ARCHITECTURE.md)
を利用できるようになりました。新しいプラグイン基盤や別の物理エンジンを
先に作る必要はありません。

1. **提示だけで成立する案**は既存の`DeviceVisualSink`と適用済み状態を使う。
   操作意図から勝手な軌道を作らず、開示や目標の表示をホストに足す。
2. **履歴を持つ案**はAtomS3側で状態を所有する。例えばC05なら、付着中は
   位置を保持し、離脱条件を満たしたフレームで遷移とイベントを同時に作る。
   同じ状態から傾き、振動、表示を導く。遷移をブラウザーだけで推測しない。
3. 新しい物理・内容状態は既存Mass/Event層等の適切な所有者へ追加する。
   試作中は既定OFFの機能フラグ等を使い、比較用の既存条件を残す。
   `HapticSynthesisCore`は順序と受け渡しを管理し、実機のStopや権限は
   `HapticPipeline`に残す。外部イベント注入APIを今回追加したわけではない。
4. 新しい状態を報告する場合は[05](../05_INTERFACE_SPEC.md)と`schemas/`、
   コーデックとクライアント受信を同時に更新する。4chの詳細タイミングを
   10Hzの最新値から復元できるとは考えない。C08の発音同期は別途設計する。
5. C04の注出は**初期設定のfill**と**時間で減るremaining**を分ける。
   fillの設定コマンドを連続送信して、毎回リセットしてはならない。
6. C07の破砕もプリセットの強制切替で位置・速度を消さず、遷移前後の
   運動と接触の整合を定義する。触感の差は実機の短い比較で確かめる。

## ブラウザーの概念スケッチの境界

`explainer/src/atlas/scenarioModel.ts`はDOM・Three.js・通信を参照しない
決定的な簡略モデルです。入力は傾き・振る・経過時間。固定ステップで
`SketchFrame`を作り、`projectCues`と`ScenarioView`が同じ状態を表示します。
30/60/120Hzの同じ入力列は同じ状態になります。停止・1コマ進行・初期化・
画面外の休止・動きを減らす設定に対応します。

この分離は試作と説明のためです。描画用の角度・粒子の配置・振動バーは
実機の単位・壁ID・校正・擬似力モデルに対応しません。FWへこのモデルを
移植したり、`webxr/`の接続表示をこれに置き換えたりしないでください。
物理出力を含む各デモの実装・検証は、次の独立した作業です。

## 原典と提案を混ぜない

- [S03 Gravity Grabber](https://www.tachilab.org/content/files/publication/ic/minamizawa200708SIGGRAPH.pdf)は指腹のベルト変形。現機とモーターの意味が違う。
- [S05 DualVib](https://yudai-tanaka.com/wp-content/uploads/2021/04/vrst20-dualvib.pdf)は方向と材質を組み合わせる根拠になるが、液体のリアリティ向上を保証しない。
- [S06 Vibr-eau](https://arxiv.org/html/2501.18755v1)は容器内の流体と振動の関連付けを扱う。注出・残量・最後の一粒はここで考案した拡張。
- [S11 Haptic Links](https://www.microsoft.com/en-us/research/wp-content/uploads/2018/02/HapticLinks_Strasnick_et_al_CHI2018-5a9063428e701.pdf)は物理的な連結。C05の内部の付着を表す合図とは能力が異なる。リポジトリのHaptic Link通信層とも別物。
- [S12 Tactile Brush](https://la.disneyresearch.com/publication/tactile-brush-drawing-on-skin-with-tactile-grid-display/)と[S13 Control Space](https://la.disneyresearch.com/wp-content/uploads/whc2011-israr-poupyrev.pdf)の皮膚上の仮現運動は、筐体上の4点へ同じ時間定数で移植できない。

予測した触感が実際に起きるか、どの条件で破綻するかを記録して初めて、
次の設計判断に使える事実になります。ここでの到達点は、選べる候補と、
作る場所と、比較の問いを具体化したことです。
